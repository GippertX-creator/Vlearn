Vlearn 教培管理系统 - Windows 安装包一键构建
================================================

【操作步骤】（全程只点鼠标，无需输入任何命令）

1. 右键本文件夹内的 build-windows.bat，选择"以管理员身份运行"
   （若没有该选项，直接双击即可，脚本会自动申请权限）

2. 弹出的黑色窗口会自动完成全部工作：
   安装 Node.js → 安装 C++ 编译工具 → 下载依赖 → 打包安装包
   全程约 20-40 分钟，请保持联网。
   中途弹出的任何窗口一律点"是 / 允许 / 确定"。
   建议先暂时关闭杀毒软件实时防护，避免误拦截。

3. 看到"构建成功"后，安装包在 release 文件夹：
   vlearn-1.0.0-win-x64.exe

4. 把安装包与《使用说明书.pdf》一起发给使用人员即可。

【备注】
- 构建只需做一次；以后要发布新版本，把新版文件夹覆盖本文件夹后重新双击脚本即可。
- 若窗口提示"构建失败"，把窗口完整截图（尤其是最后 10 行）发给技术支持。
- 安装 Node.js 失败时：先打开"微软商店"，搜索安装"应用安装程序"，再重跑脚本。
